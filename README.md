# سامانه مدیریت ساختمان ۲۰۶

نسخه اولیه واقعی Flask + SQLite، فارسی و RTL، با نقش‌های RESIDENT / ADMIN / SUPER_ADMIN.

## اجرا در Windows / Python 3.8
1. Python 3.8.10 نصب باشد.
2. در همین پوشه: `python -m pip install -r requirements.txt`
3. فایل `.env.example` را به `.env` کپی کنید و `SECRET_KEY` و `SUPER_ADMIN_PASSWORD` را تعیین کنید.
4. `python app.py --init`
5. `python app.py`
6. مرورگر: `http://127.0.0.1:5000/login`

رمز واحدها هنگام ساخت اولیه تصادفی و ناشناخته ایجاد می‌شود؛ برای تعیین رمز هر واحد از SUPER ADMIN استفاده کنید. رمز SUPER ADMIN فقط از `.env` خوانده می‌شود و در دیتابیس ذخیره یا در صفحه نمایش داده نمی‌شود.

## نکته استقرار
SQLite برای یک نمونه محلی/تک‌سرور مناسب است، اما برای استقرار دائمی روی پلتفرم‌های serverless مانند Vercel، دیتابیس پایدار بیرونی لازم است. بنابراین Deploy مستقیم این نسخه به Vercel بدون مهاجرت دیتابیس، برای سامانه واقعی توصیه نمی‌شود.
